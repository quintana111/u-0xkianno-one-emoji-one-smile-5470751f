Entry for the [One Emoji, One Smile](https://make.fun/c/u-0xkianno-one-emoji-one-smile-5470751f)
competition on [make.fun](https://make.fun): a program that writes exactly one
emoji — and nothing else — to the output file.

## The pick

🌻 — a sunflower. Warm and sunny at first glance, universal across ages and
backgrounds, gently unexpected rather than the default smiley, and friendly to
a stranger with no intimacy, sarcasm, or in-joke.

## Run

```sh
node main.ts
```

Writes the single emoji to `/output/entry.txt` (or `$ENTRY_OUTPUT_PATH` when
set), with no trailing newline.
